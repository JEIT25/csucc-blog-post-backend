## SETUP GUIDE FOR BLOG POST BACKEND BY JEROLD AMORA
## TAKE NOTE, I USE POSTGRES SQL FOR THE DATABASE, MUST BE INSTALL FIRST
STEP 1: clone or download current repo
STEP 2: run "composer install" to install all the dependencies
STEP 3: create .env file and copy paste all .env.example content
STEP 4: run "php artisan key:generate" to generate application key
STEP 5: run "php artisan migrate" to migrate database
STEP 6: run "php artisan serve" to run the app
